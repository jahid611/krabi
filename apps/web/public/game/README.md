# Icônes et images du jeu (surcharge locale)

Les visuels du jeu sont chargés depuis les CDN officiels (Data Dragon /
CommunityDragon). Un fichier présent dans ce dossier est **prioritaire** sur
le CDN — c'est ici que tu déposes tes propres images.
