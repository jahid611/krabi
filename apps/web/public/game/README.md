# Icônes du jeu (surcharge locale)

Les icônes du jeu (flash, ults, camps, objectifs) sont chargées depuis les CDN
officiels (Data Dragon / CommunityDragon). Ce dossier permet de les surcharger
en local : un fichier présent ici est utilisé en priorité.

Noms reconnus :

- `SummonerFlash.png`, `SummonerDot.png`, … (sorts d'invocateur)
- `ult-<championKey>.png` (ex. `ult-103.png` pour l'ult d'Ahri)
- `blue_buff.png`, `red_buff.png`, `gromp.png`, `wolves.png`, `raptors.png`,
  `krugs.png`, `scuttle.png`, `dragon.png`, `baron.png`, `herald.png`

Utile si un chemin CDN change de patch ou pour un usage 100% hors-ligne.
