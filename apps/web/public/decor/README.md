# Illustrations décoratives

Dépose ici tes visuels (PNG fond transparent). Les fichiers absents sont
simplement masqués — aucune image cassée à l'écran.

Noms attendus (voir `src/components/Decor.tsx` pour les positions) :

| Fichier            | Usage                                            |
| ------------------ | ------------------------------------------------ |
| `poro.png`         | États vides + gouttière gauche (Draft, Réglages) |
| `sword.png`        | Gouttière droite de la page Draft                |
| `ekko.png`         | Gouttière droite de la page En direct            |
| `ez.png`           | Gouttière gauche de la page En direct            |
| `ekko-arcane.png`  | Gouttière droite de la page Réglages             |

Ajoute/déplace des entrées dans `DECOR` (`Decor.tsx`) pour en placer d'autres.
